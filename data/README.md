# Data provenance

This repository intentionally **does not redistribute the original course-provided historical stock price and fund-return data**.

- `reported_monthly_returns_2016.csv` — numeric monthly percentage return values extracted from charts embedded in the student's submitted Capstone PowerPoint. Seven rows (Jan–Jul 2016).
- `performance_summary.csv` — calculated summary metrics from the reported seven monthly return observations (for a hypothetical $5 million starting portfolio).

To recalculate the original 2012–2015 optimal weights, supply your authorized personal copy of the fund return spreadsheet to the separate optimization script. See [`../docs/REPRODUCIBILITY.md`](../docs/REPRODUCIBILITY.md).
